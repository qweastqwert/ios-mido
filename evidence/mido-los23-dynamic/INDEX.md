# Dynamic-partition LOS23 evidence index

This directory belongs to the newly booted dynamic-partition LineageOS 23 capture.
It must remain separate from `evidence/mido-los23`, which is the older non-dynamic ROM.

| Folder | Contents |
|---|---|
| `device-tree/live/` | DTB and decompiled DTS from this ROM |
| `device-tree/dtbo/` | DTBO status marker |
| `partitions/` | Logical-partition metadata and raw layout notes |
| `boot-chain/` | Reserved for future read-only boot-image captures |

No partition was formatted, resized, or flashed during this capture.
